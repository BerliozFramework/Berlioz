It's a package to use the Twig rendering engine in Berlioz Framework.

📖 **[Full documentation](https://getberlioz.com/docs/3.x/guides/templating)**

## Installation

You can install **Twig Package for Berlioz Framework** with [Composer](https://getcomposer.org/), it's the recommended
installation.

```shell
$ composer require berlioz/twig-package
```
