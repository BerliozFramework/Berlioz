📖 **[Full documentation](https://getberlioz.com/)**

## Installation

You can install **Queue Manager Package for Berlioz Framework** with [Composer](https://getcomposer.org/), it's the
recommended installation.

```shell
$ composer require berlioz/queue-manager-package
```
